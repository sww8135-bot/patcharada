คำนำ

คู่มือฉบับนี้จัดทำขึ้นเพื่อเป็นแนวทางเบื้องต้นสำหรับบุคลากรขององค์การบริหารส่วนจังหวัด (อบจ.) ในการใช้งานเครื่องคอมพิวเตอร์และโปรแกรมพื้นฐานที่จำเป็นต่อการปฏิบัติงานประจำวัน เช่น การเปิด-ปิดเครื่อง การใช้งานระบบปฏิบัติการ การพิมพ์เอกสาร การจัดเก็บและสำรองข้อมูล การใช้งานอินเทอร์เน็ตและไปรษณีย์อิเล็กทรอนิกส์ของราชการ ตลอดจนแนวทางการรักษาความปลอดภัยของข้อมูล

เนื้อหาในคู่มือนี้เขียนขึ้นให้เข้าใจง่าย เหมาะสำหรับผู้เริ่มต้นใช้งานคอมพิวเตอร์ หน่วยงานสามารถนำไปปรับปรุงแก้ไขเพิ่มเติมให้สอดคล้องกับระบบงาน โปรแกรม และนโยบายด้านเทคโนโลยีสารสนเทศของแต่ละหน่วยงานได้ตามความเหมาะสม

บทที่ 1: รู้จักคอมพิวเตอร์และอุปกรณ์เบื้องต้น

1.1 ส่วนประกอบหลักของคอมพิวเตอร์

  • จอภาพ (Monitor): แสดงผลข้อมูลและการทำงาน
  • ตัวเครื่อง/ซีพียู (CPU/Computer Case): หน่วยประมวลผลกลาง
  • แป้นพิมพ์ (Keyboard) และเมาส์ (Mouse): อุปกรณ์นำเข้าข้อมูล
  • เครื่องพิมพ์ (Printer) และเครื่องสแกน (Scanner)
  • อุปกรณ์จัดเก็บข้อมูลภายนอก: เช่น แฟลชไดรฟ์ (Flash Drive), ฮาร์ดดิสก์พกพา (External Hard Disk)

1.2 ข้อควรปฏิบัติในการดูแลอุปกรณ์

  • วางเครื่องคอมพิวเตอร์ในที่อากาศถ่ายเทสะดวก ไม่มีฝุ่นละอองมาก
  • ไม่วางแก้วน้ำหรือของเหลวใกล้อุปกรณ์คอมพิวเตอร์
  • ปิดเครื่องให้ถูกวิธีทุกครั้งก่อนกลับบ้านหรือเลิกใช้งาน
  • แจ้งเจ้าหน้าที่ IT ทันทีเมื่อพบความผิดปกติ เช่น เครื่องร้อนจัด มีเสียงดัง หรือจอภาพกระพริบ
เกร็ดความรู้: ควรสำรองข้อมูลสำคัญอย่างน้อยสัปดาห์ละ 1 ครั้ง เพื่อป้องกันข้อมูลสูญหายจากเหตุขัดข้องของเครื่อง

บทที่ 2: การเปิด-ปิดเครื่องและการใช้งาน Windows เบื้องต้น

2.1 ขั้นตอนการเปิดเครื่อง

  1. ตรวจสอบสายไฟและสายสัญญาณต่าง ๆ ให้เรียบร้อย
  2. กดปุ่ม Power ที่ตัวเครื่องคอมพิวเตอร์
  3. กดปุ่ม Power ที่จอภาพ (หากไม่ติดอัตโนมัติ)
  4. รอระบบปฏิบัติการ Windows โหลดจนแสดงหน้าจอเข้าสู่ระบบ (Log in)
  5. กรอกชื่อผู้ใช้งานและรหัสผ่านของตนเองเพื่อเข้าใช้งาน

2.2 ขั้นตอนการปิดเครื่องอย่างถูกวิธี

  1. ปิดโปรแกรมทั้งหมดที่เปิดใช้งานอยู่ และบันทึกงานให้เรียบร้อย
  2. คลิกปุ่ม Start ที่มุมล่างซ้ายของหน้าจอ
  3. เลือกคำสั่ง Shut down หรือ ปิดเครื่อง
  4. รอจนเครื่องดับสนิทก่อนปิดสวิตช์ปลั๊กไฟ (ถ้ามี)
ข้อควรระวัง: ห้ามปิดเครื่องด้วยการกดปุ่ม Power ค้างไว้ หรือถอดปลั๊กไฟทันที เพราะอาจทำให้ข้อมูลเสียหายหรือเครื่องชำรุดได้

บทที่ 3: การใช้งานโปรแกรมพื้นฐาน (Word / Excel / PowerPoint)

3.1 Microsoft Word - งานเอกสารราชการ

  • ใช้สำหรับพิมพ์หนังสือราชการ บันทึกข้อความ รายงาน และเอกสารทั่วไป
  • ตั้งค่าหน้ากระดาษ (Page Layout) ให้ตรงตามระเบียบงานสารบรรณ
  • ใช้แบบฟอร์ม/เทมเพลตของหน่วยงานเพื่อความเป็นมาตรฐานเดียวกัน
  • บันทึกไฟล์ (Save) เป็นระยะด้วยปุ่ม Ctrl+S เพื่อป้องกันข้อมูลสูญหาย[

3.2 Microsoft Excel - งานตัวเลขและข้อมูล

  • ใช้สำหรับจัดทำทะเบียนข้อมูล บัญชี งบประมาณ และการคำนวณต่าง ๆ
  • การใส่สูตรคำนวณเบื้องต้น เช่น =SUM(A1:A10) สำหรับรวมตัวเลข
คำแนะนำ: ควรฝึกใช้แป้นพิมพ์ลัด (Shortcut Keys) เช่น Ctrl+C (คัดลอก), Ctrl+V (วาง), Ctrl+Z (ยกเลิกคำสั่ง) เพื่อให้ทำงานได้รวดเร็วขึ้น

บทที่ 4: การใช้งานอินเทอร์เน็ตและอีเมลราชการ

4.1 การใช้งานอินเทอร์เน็ตอย่างเหมาะสม

  • ใช้อินเทอร์เน็ตเพื่อการปฏิบัติงานเป็นหลัก เช่น สืบค้นข้อมูล ติดต่อราชการ
  • หลีกเลี่ยงการเข้าเว็บไซต์ที่ไม่น่าเชื่อถือหรือมีความเสี่ยงด้านความปลอดภัย
  • ไม่ดาวน์โหลดโปรแกรมหรือไฟล์จากแหล่งที่ไม่ทราบที่มา

4.2 การใช้งานอีเมลราชการ (e-Mail)

  • เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านอีเมลราชการที่หน่วยงานกำหนด
  • เขียนอีเมลโดยระบุหัวเรื่อง (Subject) ให้ชัดเจน และใช้ภาษาสุภาพเหมาะสมกับงานราชการ
  • ออกจากระบบ (Log out) ทุกครั้งหลังใช้งานเสร็จ โดยเฉพาะเมื่อใช้เครื่องคอมพิวเตอร์ร่วมกับผู้อื่น
ข้อควรระวัง: ไม่เปิดไฟล์แนบหรือคลิกลิงก์จากอีเมลที่ไม่รู้จักหรือดูน่าสงสัย เพราะอาจเป็นอีเมลหลอกลวง (Phishing) ที่นำไปสู่การถูกโจรกรรมข้อมูล

บทที่ 5: การจัดเก็บเอกสารและการสำรองข้อมูล

5.1 การจัดเก็บไฟล์อย่างเป็นระบบ

  • ตั้งชื่อไฟล์และโฟลเดอร์ให้สื่อความหมาย เช่น ระบุปี เดือน และประเภทงาน
  • จัดหมวดหมู่โฟลเดอร์ตามลักษณะงาน เช่น งานสารบรรณ งานบุคคล งานงบประมาณ
  • ลบไฟล์ที่ไม่ใช้งานแล้วออกอย่างสม่ำเสมอเพื่อประหยัดพื้นที่จัดเก็บ

5.2 การสำรองข้อมูล (Backup)

  • สำรองข้อมูลสำคัญไปยังอุปกรณ์ภายนอก เช่น External Hard Disk หรือ Flash Drive
  • กำหนดรอบเวลาสำรองข้อมูลที่ชัดเจน เช่น ทุกวันศุกร์ หรือทุกสิ้นเดือน

บทที่ 6: ความปลอดภัยของข้อมูลและการใช้งานคอมพิวเตอร์อย่างปลอดภัย

6.1 การตั้งรหัสผ่านที่ปลอดภัย

  • ใช้รหัสผ่านที่มีความยาวอย่างน้อย 8 ตัวอักษร ผสมตัวเลขและอักขระพิเศษ
  • ไม่ใช้รหัสผ่านที่คาดเดาง่าย เช่น วันเกิด หรือเบอร์โทรศัพท์
  • ไม่บอกรหัสผ่านให้ผู้อื่นทราบ และเปลี่ยนรหัสผ่านเป็นระยะ

6.3 แนวปฏิบัติด้านความปลอดภัยไซเบอร์เบื้องต้น

  • ล็อกหน้าจอเครื่องคอมพิวเตอร์ทุกครั้งเมื่อลุกออกจากโต๊ะทำงาน (กด Windows+L)[cite: 1]
  • ไม่ติดตั้งโปรแกรมที่ไม่เกี่ยวข้องกับงานราชการโดยไม่ได้รับอนุญาต
  • แจ้งเจ้าหน้าที่ IT ทันทีเมื่อสงสัยว่าข้อมูลรั่วไหลหรือเครื่องติดไวรัส
สำคัญ: ข้อมูลราชการถือเป็นทรัพย์สินของหน่วยงาน บุคลากรทุกคนมีหน้าที่ร่วมกันดูแลรักษาความปลอดภัยของข้อมูลอย่างเคร่งครัด

ภาคผนวก

คำศัพท์เบื้องต้นที่ควรรู้

  • Hardware - อุปกรณ์ที่จับต้องได้ของคอมพิวเตอร์
  • Software - โปรแกรมหรือชุดคำสั่งที่ใช้งานบนคอมพิวเตอร์
  • Phishing - กลลวงทางอีเมลหรือเว็บไซต์เพื่อขโมยข้อมูล
